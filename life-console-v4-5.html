It can currently create rota shifts, fuel logs, expenses/income, bills, savings goals and notes. Nothing is saved until you press Add.

What this is actually doing

This version runs entirely inside the page, so your pasted information stays in the browser. It uses a lightweight language parser rather than pretending it has a cloud AI model. If you later want a true ChatGPT-style model, the app would need an API/backend and an API key.
